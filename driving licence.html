Driving Licence (DL) ek zaroori document hai jo aapko vehicle chalane ki legal permission deta hai. Process do steps mein hota hai — pehle Learning Licence (LL), uske baad practice ke baad Permanent Driving Licence. Ye process Sarathi Parivahan ke official portal se online kiya ja sakta hai.

📋 Zaroori Documents

  • Aadhaar Card
  • Address Proof (Voter ID / Electricity Bill)
  • Age Proof (10th Marksheet / Birth Certificate)
  • Passport size Photo
  • Mobile Number aur Email ID (OTP verification ke liye)

📝 Learning Licence (LL) Apply Karne Ka Process

  1. Official website kholein: sarathi.parivahan.gov.in
  2. Apna state select karein (Bihar) aur "Learner Licence" option par click karein.
  3. Apni personal details, address aur documents ki details online form mein bharen.
  4. Online Learner's Test (traffic rules quiz) attempt karein aur pass karein.
  5. Fees online pay karein aur agar zaroorat ho to RTO appointment book karein.
  6. Test pass hone ke baad Learning Licence online generate ho jaata hai.

🚘 Permanent DL Apply Karne Ka Process

  1. Learning Licence milne ke 30 din baad se 6 mahine ke andar Permanent DL ke liye apply karein.
  2. Sarathi portal par "Apply for Driving Licence" option select karein.
  3. Apna Learning Licence number daal kar form bharen aur RTO mein Driving Test ke liye appointment book karein.
  4. Tay tareekh par RTO jaakar practical driving test dein.
  5. Test pass hone ke baad Permanent DL aapke address par post se ya digitally DigiLocker mein mil sakta hai.

🔍 Status Kaise Check Karein

sarathi.parivahan.gov.in par jaakar "Application Status" option se apna Application Number aur Date of Birth daal kar apni LL ya DL application ka status check kar sakte hain.
